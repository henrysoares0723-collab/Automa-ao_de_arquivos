# 📊 Análise de Dados de Vendas

Projeto desenvolvido em Python para análise de dados de vendas de diferentes lojas, com o objetivo de identificar produtos mais vendidos, faturamento por produto e desempenho das lojas.

## 🎯 Objetivo

Este projeto foi desenvolvido como parte dos meus estudos de Python e análise de dados.

O programa reúne dados de diferentes arquivos CSV e realiza análises para identificar:

- Produto mais vendido em quantidade
- Faturamento por produto
- Faturamento por loja

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Plotly Express
